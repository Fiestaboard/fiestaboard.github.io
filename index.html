What's New

The fastest way to run FiestaBoard, and updates without ever touching a terminal

New

FiestaPi - flash a Raspberry Pi, done

A pre-built Raspberry Pi OS image with FiestaBoard, Docker, and the self-update sidecar all pre-installed. Flash a microSD card with Raspberry Pi Imager, boot your Pi, open http://fiestapi.local:4420 - no Docker setup, no terminal, no config files. Works on Pi 3B, Pi 4, Pi 5, and Pi Zero 2 W.

FiestaPi Quick Start →Download image
New

One-click in-app updates

When a new version ships, a banner appears in Settings → System. Click Update Now and FiestaBoard updates itself - no SSH, no docker compose pull. On for FiestaPi by default; opt in on Docker installs by enabling the fiestaupdater sidecar.
